# تکلیف: پیاده‌سازی شبکه عصبی کانولوشنی (CNN) روی مجموعه داده MNIST

**هدف پروژه:** طراحی و پیاده‌سازی یک مدل شبکه عصبی کانولوشنی (CNN) سه لایه با استفاده از فریم‌ورک **PyTorch** جهت تشخیص اعداد دست‌نویس. 

---

## ۱. داده‌های ورودی (مجموعه داده MNIST)
* **منبع داده:** استفاده از دیتاست آماده `torchvision.datasets.MNIST`.
* **ویژگی‌ها:** تصاویر تک‌کاناله (سیاه‌وسفید) با ابعاد ۲۸×۲۸ پیکسل در ۱۰ کلاس (اعداد ۰ تا ۹).
* **پیش‌پردازش:** تصاویر باید با استفاده از `torchvision.transforms` به تنسور (Tensor) تبدیل شده و مقادیر پیکسل‌های آن‌ها نرمال‌سازی شود. داده‌ها باید توسط `DataLoader` به دسته‌هایی (Batches) با اندازه مناسب (مثلاً ۶۴) تقسیم شوند.

## ۲. الزامات ساختاری مدل (معماری ۵ لایه)
مدل باید شامل ۳ لایه دارای وزن و ۲ لایه فعال‌ساز با مشخصات زیر باشد:

* **لایه اول (Convolutional):** دارای ترم بایاس، شامل **۳۲ فیلتر** با ابعاد **۵×۵** و استفاده از پدینگ صفر (Zero-padding) به اندازه **۲ پیکسل**.
* **لایه دوم (Activation):** اعمال تابع فعال‌ساز **ReLU**.
* **لایه سوم (Convolutional):** دارای ترم بایاس، شامل **۱۶ فیلتر** با ابعاد **۳×۳** و استفاده از پدینگ صفر به اندازه **۱ پیکسل**.
* **لایه چهارم (Activation):** اعمال تابع فعال‌ساز **ReLU**.
* **لایه پنجم (Fully Connected):** مسطح‌سازی (Flatten) ویژگی‌ها و اتصال به یک لایه خطی برای محاسبه امتیازات نهایی (Scores) برای **۱۰ کلاس**.

## ۳. نیازمندی‌های پیاده‌سازی و خروجی
* **خروجی نهایی:** مدل باید روی مجموعه داده آزمون (Test Set) اجرا شده و امتیازات طبقه‌بندی (Scores) یا پیش‌بینی‌های نهایی برای نمونه‌های آزمون در فایل `scores_output.csv` ذخیره شود.
* **ساختار کد:** کد باید ماژولار بوده و از کلاس `nn.Module` برای تعریف شبکه استفاده کند. مستندسازی و کامنت‌گذاری دقیق برای هر لایه الزامی است.
