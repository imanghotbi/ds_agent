# تکلیف: بصری‌سازی داده‌ها با نمودارهای تعاملی در پایتون

**هدف پروژه:** استفاده از کتابخانه‌های بصری‌سازی پایتون برای تبدیل داده‌های خام به نمودارهای میله‌ای، خطی و پراکندگی جهت تحلیل الگوها و روندها.

---

## نیازمندی‌های بصری‌سازی و خروجی‌ها

### ۱. نمودار میله‌ای (Bar Chart)
* **مشخصات فنی:**
    * **محور افقی (x):** دسته‌بندی‌ها (Category).
    * **محور عمودی (y):** مقادیر (Values).
    * **طراحی:** هر میله نشان‌دهنده مقدار یک دسته است و تمام میله‌ها باید به رنگ **آبی** (Blue) باشند.
* **فایل خروجی:** `bar_chart.png`



### ۲. نمودار خطی (Line Chart)
* **مشخصات فنی:**
    * **محور افقی (x):** تاریخ (Date).
    * **محور عمودی (y):** مقادیر (Values).
    * **هدف:** نمایش تغییرات مقادیر در طول زمان (سری زمانی).
* **فایل خروجی:** `line_chart.png`



### ۳. نمودار پراکندگی (Scatter Chart)
* **مشخصات فنی:**
    * **محور افقی (x):** متغیر X.
    * **محور عمودی (y):** متغیر Y.
    * **کدگذاری رنگی:** دسته‌های مختلف باید با رنگ‌های متفاوت نمایش داده شوند.
    * **اندازه نقاط:** اندازه هر نقطه (Marker Size) باید متناسب با ستون "Values" باشد (Bubble Chart).
* **فایل خروجی:** `scatter_chart.png`

## داده‌های ورودی (کد پایتون)

برای انجام این تکلیف، از قطعه کد زیر برای ایجاد مجموعه‌داده اولیه استفاده کنید:

```python
import pandas as pd

# ایجاد مجموعه‌داده اولیه
data = {
    'Category': ['A', 'B', 'C', 'D'],
    'Values': [23, 17, 35, 29],
    'Date': pd.date_range(start='2022-01-01', periods=4, freq='M'),
    'X': [1, 2, 3, 4],
    'Y': [10, 11, 12, 13]
}

df = pd.DataFrame(data)
```
