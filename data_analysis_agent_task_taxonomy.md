# Data Analysis Agent Task Taxonomy

This version is a condensed taxonomy based on the scenario prompts in this workspace. It uses broader categories and lighter subtopics than the previous draft.

## 1. Data Acquisition and Integration

### 1.1 Data Access
- Load data from files, matrices, text, images, or web sources.

### 1.2 Schema Understanding
- Identify inputs, outputs, keys, labels, and task type.

### 1.3 Data Combination
- Join, align, reshape, or transpose data when needed.

## 2. Data Preparation and Quality

### 2.1 Data Quality Checking
- Check completeness, validity, consistency, and basic structure.

### 2.2 Data Cleaning
- Handle missing values, duplicates, outliers, and formatting issues.

### 2.3 Data Transformation
- Convert types, scale values, encode categories, and prepare model-ready data.

## 3. Exploratory Analysis and Visualization

### 3.1 Descriptive Analysis
- Summarize distributions, frequencies, trends, and relationships.

### 3.2 Pattern Discovery
- Explore segments, correlations, anomalies, and time-based behavior.

### 3.3 Visualization
- Create charts that clearly communicate the main findings.

## 4. Statistical Inference

### 4.1 Hypothesis Setup
- Define comparison groups, assumptions, and significance level.

### 4.2 Statistical Testing
- Run distribution tests or group-comparison tests.

### 4.3 Interpretation
- Explain the statistical result and its practical meaning.

## 5. Feature Engineering

### 5.1 Feature Creation
- Build derived variables, aggregates, and domain-specific features.

### 5.2 Representation
- Create text, reduced-dimension, or task-specific feature representations.

### 5.3 Label Construction
- Create targets or grouping labels from rules or thresholds.

## 6. Predictive Modeling

### 6.1 Supervised Learning
- Train regression, classification, or deep learning models.

### 6.2 Recommendation and Similarity
- Build recommendation or similarity-based models when required.

### 6.3 Optimization-Based Modeling
- Use search or optimization methods to improve model performance.

## 7. Unsupervised Learning and Pattern Mining

### 7.1 Clustering
- Group similar samples or entities into clusters.

### 7.2 Cluster Interpretation
- Describe cluster meaning, size, and practical use.

### 7.3 Rule Mining
- Extract association rules or other hidden data patterns.

## 8. Evaluation and Validation

### 8.1 Data Splitting and Validation
- Use train/test splits, validation, or cross-validation.

### 8.2 Performance Measurement
- Evaluate with suitable metrics for the task.

### 8.3 Model Comparison
- Compare candidate methods and choose a final approach.

## 9. Prediction and Decision Outputs

### 9.1 Prediction Generation
- Produce predictions, scores, rankings, or recommendations.

### 9.2 Decision Support
- Convert outputs into labels, selections, or actions.

### 9.3 Deliverables
- Save the required files, reports, and final artifacts.

## Suggested Category List

If you want the short category set only, use:

1. Data Acquisition and Integration
2. Data Preparation and Quality
3. Exploratory Analysis and Visualization
4. Statistical Inference
5. Feature Engineering
6. Predictive Modeling
7. Unsupervised Learning and Pattern Mining
8. Evaluation and Validation
9. Prediction and Decision Outputs

## Main Changes from the Previous Version

- Merged data quality and preprocessing into one broader category.
- Merged exploratory analysis and visualization into one broader category.
- Reduced subtopics to shorter, more general capability groups.
- Kept the taxonomy aligned with the scenario set while making it easier to use in a figure or benchmark rubric.
